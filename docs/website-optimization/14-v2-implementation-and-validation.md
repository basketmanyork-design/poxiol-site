# Homepage UX V2 implementation and validation — 2026-09-16

## Delivered in the review branch

- Preserved the approved nine-module homepage order and the six existing product routes.
- Kept the full-width immersive Hero video structure. The video remains a background layer with poster fallback, while the H1 and both CTAs remain live HTML.
- Rebalanced the homepage visual system: system font stack, lighter editorial dividers for the customization/FAQ sections, a clearer two-audience split, compact sample review structure, and an explicit CTA hierarchy.
- Preserved the three-group project inquiry form and all confirmed procurement fields. The homepage now has one visible inquiry H2; the embedded form retains its grouped H3 headings.
- Added Team / School / Club and Brand / Reseller URL hints from the two audience cards. The form preselects the matching optional buyer type but keeps buyer edits authoritative.
- Corrected a real React hydration mismatch in the country selector. Country labels are now static rather than generated by runtime locale data, avoiding browser/server disagreement such as `Falkland Islands` versus `Falkland Islands (Islas Malvinas)`.
- Made mobile fixed layers coexist safely: the inquiry bar leaves the Hero and visible form interaction trees; opening the mobile menu removes competing fixed layers; the analytics choice panel moves to the safe-area edge when that bar is absent and compresses at 320px.
- Added a finite cache rule for stable `website-optimization` assets. The Hero preloads its poster only, not the MP4.
