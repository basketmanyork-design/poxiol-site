# Hero background revision for review

The previous V1.1 Preview `0a65d532` rendered a two-column hero with a right-hand video player and controls. This revision changes only the homepage hero presentation; the nine module order, procurement form, categories, Sanity fields and original supplied media remain as in V1.1. LuxoPack is the visual direction for immersive media under HTML copy, not a source of POXIOL claims or assets.

The hero is one full-width relative, isolated and overflow-hidden section, with a 680–900px desktop height and 650–760px suggested mobile height. The copied H.264/MP4 is absolute, fills the hero with `object-fit: cover`, uses 57%/49% desktop and 68%/50% mobile focal positions, and has autoplay/muted/loop/playsInline with no controls or player framing. The existing 194,158-byte image `/images/poxiol-teamwear-range-banner-2x1.webp` is the poster and CSS background, so it is visible before video hydration and whenever media cannot play. The left-heavy desktop gradient and deeper vertical mobile gradient support white HTML text and keep the garment/process visible on the right. The copy is capped at 620px desktop and fills the width on mobile; both CTAs remain regular links above the media layers.

`HeroBackgroundVideo.tsx` renders an SSR poster-only `<video>` without a source and attaches the 4,644,204-byte supplied MP4 only after hydration when `prefers-reduced-motion` is off and `navigator.connection.saveData` is false. Playback errors remove the video node and reveal the same CSS Poster. Changes to the motion preference remount the poster video node, preventing a paused last frame from replacing the Poster. The image cards below the hero retain `loading="lazy"`.
